The rules

Each agent sees its current cell and its eight neighbors. Usually it chooses the cell with the most food; ties are random. It has a 30% × exploration chance of trying a random neighboring cell instead. If it sees no food, it searches a neighboring cell.

The active preset starts each agent with {{ model.environment.starting_resources }} resources and has {{ model.environment.patches | length }} patches, each starting with {{ model.environment.food_per_patch }} food.

Move at most one cell, collect all its food, pay {{ model.environment.movement_cost }} if moving, pay {{ model.environment.survival_cost }} to survive, and age by one. After everyone's turn, patches regrow by {{ model.environment.regeneration }} up to capacity. Death happens at zero resources or age {{ model.environment.maximum_age }}. If both happen on the same turn, the death is counted as starvation.

Agents can share a cell. Earlier arrivals take the available food first. Encounters mean the same cell (distance 0) or adjacent cells, including diagonals (distance 1). They have no consequences. There is no fighting, sharing, or reproduction yet. Both populations follow the same rules.
